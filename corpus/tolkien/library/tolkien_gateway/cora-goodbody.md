# Cora Goodbody

Source: https://tolkiengateway.net/wiki/Cora_Goodbody

Cora Bolger, née Goodbody, was a Hobbit of the Shire.


== History ==
Cora married Rudolph Bolger. They had one son, Fastolph, born S.R. 1210.


== Etymology ==
The name Cora was meaningless in contemporary Hobbitish Westron. It represented an original name Coro or Core.
