# Gilbarad

Source: https://tolkiengateway.net/wiki/Gilbarad

Gilbarad was the father of Ivorwen, and Aragorn's maternal great-grandfather.


== Etymology ==
Gilbarad is a Sindarin name. Its meaning is not glossed, but Paul Strack suggests that it contains the elements gil ("star; (bright) spark, silver glint, twinkle of light") and barad ("tower, great towering building").
