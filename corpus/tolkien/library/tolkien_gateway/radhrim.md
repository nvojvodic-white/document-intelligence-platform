# Radhrim

Source: https://tolkiengateway.net/wiki/Radhrim

Radhrim (Raðrim) was a forested region in eastern Doriath, located between the rivers Aros and Celon. Although what appears to be the same region is also called Arthórien, it is unknown if these two regions were the same (or if one was situated within the other). 


== Etymology ==
In the Etymologies, the Doriathrin name Radhrim is glossed as "East-march".
