# Rufus Burrows

Source: https://tolkiengateway.net/wiki/Rufus_Burrows

Rufus Burrows was a Hobbit of the Shire.


== History ==
Rufus married Asphodel Brandybuck, and had one child, Milo. They attended Bilbo's Birthday Party along with Milo's children.


== Etymology ==
Rufus is a Latin name meaning "red-haired".
